### 蔡司增距鏡
這次記者會另一個主角，是 vivo 的蔡司外掛增距鏡。根據官方新聞稿，X500 Pro Max 搭配 **G2 Ultra** 增距鏡，等效焦段可以延伸到 400mm；X500 Pro 與 X500 則搭配 **G2** 增距鏡，延伸至 200mm。就連摺疊旗艦 X Fold6，這次也是市場上首發支援專屬增距鏡的大螢幕摺疊機。

而 X500 Pro Max 攝影師套裝，則是把 G2 Ultra 與 G2 兩支增距鏡、影像手柄、影像保護殼與相關配件一次打包，適合本來就打算把手機當成相機來用的玩家。

### 外觀與手感
X500 Pro Max 延續了 X 系列的大圓形鏡頭模組，而我手上的星空灰是玻璃背蓋版本，厚度 8.12mm、重量 230.3 公克。以一台塞進 2 億畫素長焦與 7800mAh 電池的影像旗艦來說，這組數字已經相當克制。

![外觀](待補)

{% comment %}
待補：
1. 星空灰在不同光線下的顏色表現、背蓋觸感（霧面？會不會沾指紋？）。
2. 單手握持的感受、鏡頭模組的凸起程度、放在桌上會不會晃。
3. 中框材質與按鍵手感。
4. 和你手上其他手機放在一起的對比照。
{% endcomment %}

### 螢幕
X500 Pro Max 配備 6.85 吋 2K AMOLED 螢幕，解析度 3168 × 1440，像素密度 507 ppi，支援最高 144Hz 更新率與 P3 廣色域。

{% comment %}
待補：
1. 戶外陽光下的可視度。
2. 夜間低亮度的使用感受（官網沒有列 PWM 調光規格，系統內如果有護眼相關設定可以截圖）。
3. 144Hz 在哪些 App 有開、哪些沒開。
4. 超聲波指紋的解鎖速度與位置。
{% endcomment %}
